# Massera

**Massage, spa, and wellness marketplace**

Massera is a booking marketplace for real-world massage, spa, and wellness services, with dedicated experiences for clients, providers, and spa teams.

## Project scope

- Service discovery and booking flows
- Client, provider, and spa workspaces
- Mobile app, admin tools, and backend integrations

**Technology:** Flutter and Dart, Next.js, Supabase and PostgreSQL.
